# 🛒 Flipkart Clone – Frontend Project

A fully responsive **Flipkart Clone built using HTML, Tailwind CSS, and Vanilla JavaScript**.  
This project focuses on **real-world frontend functionality** like product rendering, live search, cart system using LocalStorage, and a clean UI similar to the original Flipkart website.

---

## 🚀 Live Features

✅ Modern Flipkart-style Navbar  
✅ Categories Section  
✅ Promotional Banner  
✅ Dynamic Product Listing  
✅ Live Search Functionality  
✅ Add to Cart System  
✅ Persistent Cart using LocalStorage  
✅ Cart Page with Quantity Control & Total Price  
✅ Responsive Design  
✅ Professional Footer  
✅ Social Media SVG Icons  

---

## 🧰 Tech Stack Used

- **HTML5** – Structure  
- **Tailwind CSS** – Styling & Responsiveness  
- **JavaScript (ES6)** – Logic & Interactivity  
- **LocalStorage** – Cart Data Persistence
